# Product Principles

## Promise
Kidan is a private introduction service, not a public social network. It helps verified Orthodox Christian adults discover compatible people without publishing their identities or allowing unsolicited contact.

## Required connection ceremony
A connection may open only when all conditions are true:

1. Both profiles are active and administrator-approved.
2. User A independently expresses interest in User B.
3. User B independently expresses interest in User A.
4. An authorized administrator approves the introduction using published criteria.
5. User A and User B each confirm that they still want to open the connection.

Until then, no name, phone number, Telegram username, direct-message link, or conversation channel is exposed.

## Discovery
- Values-first, calm, and finite; no addictive infinite feed.
- No super-likes, popularity scores, profile-view receipts, online status, or public counters.
- Discovery shows only coarse and approved attributes.
- Swipe gestures always have equivalent visible buttons.
- Passing is private. One-sided interest is never disclosed.

## Orthodox context
The first release is limited to adult Ethiopian Orthodox Tewahedo Church candidates. Faith information is user-provided sensitive data. The app supports intentional marriage-oriented preferences without ranking spiritual worth or generating a theological compatibility score. Sacred imagery is treated respectfully and is not used as swipe decoration.

## MVP
- Telegram authentication
- Private identity and adult verification
- Profile creation and admin approval
- Values-only anonymous discovery with no candidate photos
- Pass/interested decisions
- Mutual-interest detection
- Admin introduction approval
- Final confirmation by both users
- Restricted in-app introduction after every approval gate
- Optional later contact exchange only with a new mutual consent
- Block, report, pause, and deletion

Payments, AI matching, public discovery photos, and unrestricted messaging are out of scope.
